# Prefix Sum Pattern Notes (DSA)

--------------------------------------------------

1. What is Prefix Sum?

Prefix Sum means:

Store cumulative sums while moving from left to right.

Example:

nums = [1,7,3,6,5,6]

Prefix sums:

[1,8,11,17,22,28]

Because:

1
1+7 = 8
1+7+3 = 11
etc.

--------------------------------------------------

2. When Should I Think About Prefix Sum?

Whenever question contains:

- sum of left side
- sum of right side
- subarray sum
- range sum
- cumulative sum
- before current index
- after current index
- equal left and right
- continuous sum

Immediately think:

PREFIX SUM

--------------------------------------------------

3. Mental Questions To Ask During Problem Solving

STEP 1:

What information do I need at every index?

Example in Pivot Index:

Need:
- left sum
- right sum

--------------------------------------------------

STEP 2:

Can I calculate repeatedly?

Brute Force:

for every index:
    calculate left
    calculate right

This becomes O(n²)

Bad.

--------------------------------------------------

STEP 3:

Can I store previous calculations?

YES.

This becomes Prefix Sum.

--------------------------------------------------

4. Most Important Formula

Always remember:

TOTAL = LEFT + CURRENT + RIGHT

Therefore:

RIGHT = TOTAL - LEFT - CURRENT

This is the core formula of Pivot Index.

--------------------------------------------------

5. Why leftSum Update Happens After if()

At current index:

leftSum should contain ONLY elements before current index.

Example:

[1,7,3,6,5,6]
         ^

At index 3:

LEFT = 1+7+3 = 11

Current element 6 should NOT be inside leftSum.

So:

1. calculate rightSum
2. compare
3. THEN move current element into left side

That is why:

leftSum += nums[i];

comes AFTER if statement.

--------------------------------------------------

6. Visual Thinking Pattern

Always imagine:

[ LEFT ] [ CURRENT ] [ RIGHT ]

At every index:

leftSum = LEFT
nums[i] = CURRENT
rightSum = RIGHT

--------------------------------------------------

7. Generic Prefix Sum Coding Pattern

PATTERN:

1. Calculate total
2. Keep leftSum
3. Traverse array
4. Derive rightSum mathematically
5. Compare
6. Update leftSum

8. Standard Prefix Sum Template

int totalSum = 0;

for(int num : nums){
    totalSum += num;
}

int leftSum = 0;

for(int i = 0; i < nums.length; i++){

    int rightSum = totalSum - leftSum - nums[i];

    // use condition here

    leftSum += nums[i];
}

13. Pivot Index Solution

class Solution {

    public int pivotIndex(int[] nums) {

        int n = nums.length;

        int totalSum = 0;

        for(int num : nums) {
            totalSum += num;
        }

        int leftSum = 0;

        for(int i = 0; i < n; i++) {

            int rightSum = totalSum - leftSum - nums[i];

            if(leftSum == rightSum) {
                return i;
            }

            leftSum += nums[i];
        }

        return -1;
    }
}
